# Troubleshooting

Find your failure below. Every entry names the real error text, the cause, and the fix. Start with [`docs doctor`](../cli/doctor.md) when unsure.

- [Installation](installation.md) — Node, install, peers, registry, monorepo issues.
- [Configuration](configuration.md) — validation errors, unknown keys, path problems.
- [Content discovery](content-discovery.md) — missing pages, ignored files, duplicates, bad dates.
- [Rendering](rendering.md) — entry points, payloads, leaks, CSS, search artifacts.
- [Ownership and safety](ownership-safety.md) — unexpected deletions (or lack of them), clean refusals, markers.
- [CLI failures](cli-failures.md) — ports, names, roots, exits, malformed requests.
